## Goodreads Integration (`src/hooks/useBooks.js`)

### Architecture

The entire Python matching pipeline (`match_goodreads_feira.py`) was ported to JavaScript and runs client-side at onboarding time. A Cloudflare Worker CORS proxy bridges the browser to Goodreads's RSS feeds.

```
WORKER_URL = 'https://goodreads-proxy.beatrizfeliciano1999.workers.dev'
```

### localStorage keys

| Key | Contents |
|---|---|
| `feira_goodreads_id` | Goodreads numeric user ID |
| `feira_books_cache` | JSON array of matched book objects (avoids re-fetching) |
| `feira_book_state` | `{ [isbn]: { wantToBuy, bought } }` |
| `feira_manual_books` | `{ [isbn]: fullBookObj }` — see plan 04 for migration from old `feira_manual_isbns` |
| `feira_hidden_books` | `[isbn, …]` — books removed via the trash button (see plan 04) |

### Data flow

1. On mount: fetch `feira_books.json` (5809 books) → `faireBooks` state
2. If `userId` is set and no cache: run `fetchAndMatch()` → cache result → `rawBooks` state
3. If `userId` is set and cache exists: restore from cache immediately
4. `books` = `rawBooks` + `manualBooks` + live `bookState` overlay

### `fetchAndMatch(userId, faireBooks, onProgress, signal)`

Fetches 4 Goodreads RSS shelves in sequence, deduplicates across shelves, then runs 3 matching steps — an exact port of `match_goodreads_feira.py`:

**Step 1 — ISBN matching**
Try `isbn13`, then `isbn`, then last-10 digits of either. O(1) lookup against `faireBooks` object.

**Step 2 — Fuzzy title + author matching**
Score = `token_sort_ratio(title) × 0.75 + max(ratio(author_last, word)) × 0.25`.
Pre-filters candidates via an inverted word index to avoid O(n×m) full scan.
Accept threshold: 72 (same default as Python script).

**Step 3 — Author-only matching**
Looks up all author words in a per-word index, verifies with `authorExactMatch()` (token_sort_ratio == 100), then ranks remaining candidates by title-only score with variable thresholds:
- 1 candidate → accept if score ≥ 20 (may be a translated title)
- 2–3 candidates → accept if score ≥ 55
- 4+ candidates → accept if score ≥ 65

### Normalisation

`normalise()` is an exact JS port of Python's `normalise()`:
```js
s.toLowerCase().normalize('NFD').replace(/\p{Mn}/gu, '').replace(/[^a-z0-9 ]/g, ' ').replace(/\s+/g, ' ').trim()
```

### Progress messages

`yieldToUI()` (`setTimeout(resolve, 0)`) is called between steps so React can repaint the loading spinner with the updated `loadingMessage` string before the CPU-bound matching runs.

### Manual books

> **Superseded by plan 04.** The original implementation stored only ISBNs (`feira_manual_isbns`) and looked up book data from `faireBooks` at render time — which broke for non-LDD books. See plan 04 for the full rewrite that stores complete book objects in `feira_manual_books`.

## Static Data Files

### `app/public/feira_books.json`
Generated by `generate_feira_books.py`. 5809 books (all "livros do dia" — books with at least one discount date), keyed by ISBN-13.

**Fields per entry:**
```json
{
  "titulo": "…",
  "autor": "…",
  "participante": "EDITORA NAME",
  "stand": "H28",
  "pvp": "20.00",
  "pvp_feira": "16.00",
  "pvp_livro_do_dia": "12.00",
  "datas": ["2026-06-04", "2026-06-10"],
  "cover": "https://feiradolivrodelisboa.pt/…"
}
```

**HTML entity fix:** `generate_feira_books.py` applies `html.unescape()` to all text fields via:
```python
import html
u = lambda s: html.unescape(s or '')
```
This decodes `&#8217;` → `'`, `&#8211;` → `–`, etc. before writing the JSON.

Note: `matched_books.csv` (legacy, no longer used by the app) still has raw entities in the `feira_participante` column.

## Map Popup Portal Rewrite (`src/pages/MapPage.jsx`)

### Problem
The popup was rendered inside `.map-viewport` (which has `overflow: auto`), causing it to be clipped. Z-index overrides had no effect.

### Solution: `createPortal` + `position: fixed`

The popup is rendered via `ReactDOM.createPortal` directly into `document.body`, positioned with `position: fixed` using viewport-pixel coordinates computed from `e.currentTarget.getBoundingClientRect()`.

```jsx
const popupPortal = selectedStand && coords && createPortal(
  <div className="map-popup-anchor"
    style={{ position: 'fixed', top: popupPos.top, bottom: popupPos.bottom, left: popupPos.left, zIndex: 9999 }}>
    <StandPopup … />
  </div>,
  document.body
)
```

### 4-direction placement algorithm (`placePopup`)

Tries right / left / above / below the anchor point, measures the visible area of each candidate position, picks the one with the maximum visible area. Perpendicular clamping only (no sliding along the gap axis, to prevent covering or drifting from the marker).

For the "above" direction, uses CSS `bottom` anchoring (`vh - (anchorY - GAP)`) instead of `top`, so the popup's bottom edge is always at a fixed distance from the marker regardless of the popup's actual height.

```js
const candidates = [
  { l: anchorX + GAP,       t: anchorY - PH/2,     cssBottom: null,              freeY: true  }, // right
  { l: anchorX - GAP - PW,  t: anchorY - PH/2,     cssBottom: null,              freeY: true  }, // left
  { l: anchorX - PW/2,      t: anchorY - GAP - PH,  cssBottom: vh-(anchorY-GAP),  freeX: true  }, // above
  { l: anchorX - PW/2,      t: anchorY + GAP,       cssBottom: null,              freeX: true  }, // below
]
```

### Auto-open for `openStand` prop

When `openStand` is set (by clicking 📍 from another page), the popup is opened programmatically once the map image has loaded (`imgLoaded` state + `onLoad` handler). An `AbortController` is used to cancel any in-flight Goodreads fetch.

### Scroll/resize close

A `useEffect` adds `scroll` and `resize` listeners that close the popup, preventing stale positioning after the user scrolls or resizes.

## Hash-based Tab Routing (`src/App.jsx`)

Tabs now reflect and restore from the URL hash so a page refresh keeps the user on the same tab.

```js
const VALID_TABS = new Set(['books', 'days', 'map', 'catalog'])

function getTabFromHash() {
  const hash = window.location.hash.replace('#', '')
  return VALID_TABS.has(hash) ? hash : 'about'
}

function setHash(tab) {
  if (tab === 'about') {
    // Remove hash entirely to avoid trailing '#'
    history.pushState(null, '', window.location.pathname + window.location.search)
  } else {
    window.location.hash = tab   // fires hashchange
  }
}
```

- Initial state: `useState(getTabFromHash)` reads the hash on first render
- `useEffect` listens to `hashchange` for browser back/forward navigation
- `navigate(tab)` replaces all `setTab()` calls; handles `pushState` case (about) by setting state directly since `pushState` doesn't fire `hashchange`

## ShelfBadge null guard (`src/components/ShelfBadge.jsx`)

Manually added books have `gr_shelf: null`. Without a guard, `ShelfBadge` rendered a `shelf-badge--null` CSS class. Fix:

```jsx
export function ShelfBadge({ shelf }) {
  if (!shelf) return null
  return <span className={`shelf-badge shelf-badge--${shelf}`}>{LABELS[shelf] || shelf}</span>
}
```

## Pagination (`src/pages/CatalogPage.jsx`, `src/pages/BooksPage.jsx`)

Both pages now paginate at 50 items per page.

**Behaviour:**
- Page resets to 1 when filter/query changes (`useEffect` on the filter deps)
- Page change scrolls to top: `window.scrollTo({ top: 0, behavior: 'instant' })` (works because `app-main` has no `overflow`, so the page body scrolls)
- Pagination controls only render when `totalPages > 1`

**UI:** `‹ Anterior · X / Y · Próxima ›` centered below the list, styled with `.pagination` / `.pagination__btn` / `.pagination__info` CSS classes.
